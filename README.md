# 大学生成长档案库

一个零代码、纯可视化操作的大学生成长档案管理系统。自动整理活动经历、预估综测加分、生成申报表，还能用于奖学金答辩PPT和实习简历。

## 快速开始

### 第一次使用

1. **双击打开 `index.html`**（用 Chrome 或 Edge 浏览器）
2. 初始化向导会引导你完成三步：
   - 填写学生基本信息（姓名、学号、学院、专业等）
   - 粘贴或上传学院综测细则文本（系统自动提取加分项目、分值和证明要求）
   - 检查提取的规则，标记为"待确认"的可手动修改
3. 完成后进入主界面，开始使用

### 日常使用

1. 参加活动/比赛后，将截图、证书、作品等材料放入 `materials/` 下对应分类文件夹
   - 命名格式：`日期_活动名_材料类型.后缀`（如 `2025-03-15_数学建模国赛_证书.jpg`）
   - 系统会自动解析文件名，合并同一活动的多份材料
2. 打开 `index.html`，在"材料管理"页导入新文件
3. 在"经历管理"页确认系统自动生成的经历草稿，选择匹配的综测规则
4. 系统自动预估加分，并在"缺失提醒"页提示哪些经历缺少证明材料

### 学年末

| 场景 | 操作 | 产出 |
|------|------|------|
| 综测申报 | `python generate_zongce.py` | Markdown + CSV 申报表，含分值汇总和缺失提醒 |
| 奖学金答辩 | `python generate_ppt.py` | HTML 幻灯片，自动筛选高光经历 |
| 找实习 | `python generate_resume.py resume 技能词` | 按技能筛选的 Markdown 简历 |
| 作品集 | `python generate_resume.py portfolio` | HTML 作品集，时间线 + 卡片展示 |

## 材料文件命名规范

系统通过文件名自动识别日期、活动名称和材料类型：

```
YYYY-MM-DD_活动名称_材料类型.扩展名
```

| 示例文件名 | 解析结果 |
|------------|----------|
| `2025-03-15_数学建模国赛_证书.jpg` | 日期: 2025-03-15, 活动: 数学建模国赛, 类型: 证书 |
| `2025-03-15_数学建模国赛_作品.pdf` | 与上者合并为同一活动 |
| `2025-06-01_英语六级_证书.jpg` | 日期: 2025-06-01, 活动: 英语六级, 类型: 证书 |

同一日期 + 同一活动名的文件会自动合并为一条经历。

## 命令行工具

```bash
# 从综测细则文本提取规则
python core.py extract-rules 细则.txt

# 扫描 materials 目录
python core.py scan

# 分析材料，生成经历草稿
python core.py analyze

# 查看综测分预估
python core.py score

# 检查缺失材料
python core.py missing

# 列出所有经历
python core.py list
```

## 常见问题

**Q: 综测细则每年会变怎么办？**
A: 每年开学时在页面"设置"页重新粘贴新细则即可，历史经历会自动重新计算。

**Q: 提取的规则不准确怎么办？**
A: 初始化向导中所有规则都可在表格中直接编辑，标记为"待确认"的项需人工核实后修改。

**Q: 材料放错文件夹怎么办？**
A: 直接移动文件到正确文件夹，重新在页面导入即可。

**Q: 数据安全吗？**
A: 所有数据存储在本地，不上传任何服务器。建议定期备份 `data/` 和 `materials/` 文件夹。
